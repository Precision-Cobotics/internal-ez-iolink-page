Version 1.6.0.1 · PolyScope 5

EZ-IOLink connects a Universal Robots controller to Balluff IO-Link masters. Use it to name ports, read process data, and write process data from a robot program, including writes tied to program state and digital inputs.

Download iolink-1.6.0.1.urcap

Also listed on the v1.6.0.1 release.

Install

  1. On the robot, open Settings, then System, then URCaps.
  2. Press + and select iolink-1.6.0.1.urcap.
  3. Restart PolyScope.

After restart, open the installation and run Connect so each port can identify its device.

In this version

  • A port keeps its saved device when a scan misses it, so IO-Link Write nodes stay configured.
  • Conditional writes can follow standard digital inputs and configurable inputs, as well as program state.
  • Saving a conditional write stores one condition, so a program no longer reloads a single write as many cards.
